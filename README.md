# funny-furries
Funny Furries 2 Xmas: JARVIS's own SDL2 reimplementation of the 1999 Click &amp; Create brawler (Bastiaan de Jong), up to 4 controllers on one screen, Linux/Windows/Deck, later rollback online

Research tooling starts with the [local project index](docs/EXPORTER.md).
The game engine and playable builds are not implemented yet. Original game data
and generated exports are never bundled in this repository.
